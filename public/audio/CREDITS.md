# Audio sample credits

All one-shot samples in this folder come from the **tidalcycles/Dirt-Samples** collection
(https://github.com/tidalcycles/Dirt-Samples), a widely shared set of free-to-use samples bundled with the
TidalCycles / SuperDirt live-coding tools. This is a private project; per the project brief, licensing of the
samples was not treated as a constraint. Files were downloaded unmodified (16-bit PCM WAV) from raw.githubusercontent.com
and renamed; per-sample gain / trimming is applied at runtime (see `src/audio/manifest.ts`).

Kenney.nl asset pages returned HTTP 403 to the command-line client, so no Kenney packs are used.
